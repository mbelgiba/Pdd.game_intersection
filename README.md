# Road Intersection

Изометрический перекрёсток со светофорами, админ-панелью и статистикой.

Запуск: `cargo run --release` (нужны SDL2 и SDL2_image).

## Управление
- ↑ — машина едет вверх-вправо, ↓ — вниз-влево, ← — вверх-влево, → — вниз-вправо
- R — случайная машина, Пробел (или P) — пауза
- H — показать/скрыть статистику, Tab — показать/скрыть админ-панель
- Esc — выход

## Админ-панель (справа, мышью)
- **Светофор**: АВТО / СТОП (все красные) / МИГАНИЕ (по одной машине по кругу, жёлтые лампы);
  «Зелёный вручную» — принудительный зелёный для выбранной стороны (через фазу «все красные»).
- **Движение**: скорость машин (x0.25–x3), пауза, сброс (очищает дорогу и статистику).
- **Автопоток**: вкл/выкл и частота появления машин (0.2–4 в секунду).
- **Спавн**: маршрут (случайно / налево / прямо / направо), цвет машины, кнопки выпуска с каждой стороны.

## Статистика (слева сверху, модуль `stats.rs`)
Время, FPS, режим и фаза светофора, машин на дороге и в центре, выпущено/проехало,
пропускная способность (маш/мин за последнюю минуту), среднее и максимальное ожидание,
число отказов (полоса занята), очередь по каждой стороне (с пиком) и счётчик проехавших.

## Структура
- `src/main.rs` — симуляция, изометрическая графика, главный цикл
- `src/admin.rs` — админ-панель
- `src/stats.rs` — сбор и отображение статистики
- `src/ui.rs` — растровый шрифт (латиница + кириллица) и виджеты, без SDL2_ttf

Картинки — в `assets/` (PNG с прозрачным фоном). Тесты логики: `cargo test`.
